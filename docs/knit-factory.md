| 편직처별 우리 작업 이력 | **넣음** — 이 편직처로 적힌 설계서 · 생산 현황 오더 |
| 엑셀 내보내기 | 안 함 (대표님: 없어도 됨) |

## 2. 화면

- **[편직처별]** 왼쪽 목록(검색 · 지역 칩 · '확인 필요 N' 칩) → 오른쪽 한 곳 보기
  - 머리: 이름 · 지역 · 확인일 배지 · 기계 N대/줄 · 종류 칩 · [오늘 확인함] · [수정]
  - 연락처(전화·팩스·담당자 — 누르면 전화) · 주소(여러 개) · 편직료(여러 줄 글자)
  - **기계 현황 표** — 종류(싱글·더블·자카드·기타) → 세부 종류(엑셀의 '싱글(SPAN)'·'쥬리' 같은 묶음 이름)로 묶어서
    칸: 세부 종류 · 대수 · 인치 · 피더 · 침수 · 게이지(가마) · 가마수 · 제조사 · 메모
  - **메모** — 남기기(Ctrl+Enter) · 고치기 · 지우기, 누르면 바로 저장. 엑셀 비고(소재다양 · 스판 NO. …)는 '엑셀 비고에서 옮김' 메모 하나로
  - **우리 작업 이력** — 설계서(`knitting.factory`) · 생산 현황 오더(`steps.knitting.vendor`)가 이 편직처 이름과 같은 것 (띄어쓰기·대소문자 무시). 설계서는 누르면 열림
- **[기계로 찾기]** 모든 편직처 기계 줄을 한 표로 — 게이지 · 인치 · 종류 · 제조사 · 지역 · 검색어(세부 종류 · 메모 · 편직처)
  - **근접 포함**(기본 켬): 게이지 ±1G · 인치 ±2" 도 보여 줌 — 딱 맞는 줄이 먼저, 근접 줄은 노란 '근접'
  - 줄을 누르면 그 편직처 보기로
- **[엑셀 가져오기]** 예전 엑셀을 읽어 미리보기 → 고른 편직처만 저장 (§4)
- **[+ 편직처 추가] / [수정]** 입력 창 — 기본 정보 · 담당자 여러 명 · 주소 여러 개 · 편직료 · 종류마다 [+ 줄 추가] · 줄 복사 · 지우기
  - 게이지 칸에 '28, 30, 32'처럼 여러 개 (= 그 인치에 낄 수 있는 가마들)
  - 침수를 비우면 화면에 **≈ 계산 값**(게이지 × 3.14 × 인치, 회색) — 저장은 안 함, 게이지가 하나일 때만
  - 저장 안 한 변경이 있으면 닫기 전에 '저장할까요?' (팝업 규약)
- **설계서 편직 사양 [기계 현황에서 고르기]** — 설계서 게이지 · 인치로 먼저 거른 [기계로 찾기] → 줄(게이지 칩)을 고르면 '바뀌는 칸'(지금 값 → 새 값) 확인 → [설계서에 넣기]
  - 넣는 칸: 편직처 · 게이지 · 인치 · 침수(기계 현황에 적힌 값, 가마가 하나인 줄만) · 피더(숫자만일 때). 비어 있는 값은 설계서 칸을 그대로 둠
  - 가마가 여러 개인 줄은 게이지를 골라야 넣을 수 있음. 설계서 저장은 설계서 창에서
  - 창은 body에 바로 띄움(포털) — 설계서 창 배경 흐림(backdrop-blur) 안에서는 fixed 창이 잘려 보였음

## 3. 데이터 (`knitFactories` 문서 — 자세한 건 `utils/knitFactoryModel.js` 머리 주석)

```
{ id, name, phone, fax, contacts: [{ id, name, mobile }], addresses: [..], region, knitFee,
  machines: [{ id, category: 'single'|'double'|'jacquard'|'etc', group, count, inch, feeder(글자), needles, cylinders(가마수), gauges: [..], maker, note }],
  memos: [{ id, date, text, by, editedAt?, editedBy? }], checkedAt: 'YYYY-MM-DD', source: 'excel'?,
  createdAt, createdBy, updatedAt, updatedBy }
```

- 저장 · 메모 · 확인일 · 가져오기: `hooks/domains/useKnitFactory.js`
  - 이름 겹침 막음(띄어쓰기·대소문자 무시) · 이름을 바꾸면 '설계서 N건에 적힌 예전 이름은 그대로' 확인
  - 삭제: 기계 줄 · 메모 같이 지워짐 확인. 설계서 이름 · 설계서 편직처 목록은 그대로
  - 입력 창 저장은 메모를 덮지 않음 (메모는 창 밖에서 바로 저장되므로 저장소 값 유지)
- 설계서 편직처 목록에 넣기: `App.addKnittingFactoryNames` (없는 이름만 `writeSettingsList('knittingFactories', { add })`)

## 4. 엑셀 가져오기 규칙 (`parseKnitFactorySheet`)

- 머리 줄 = '기계수' 칸이 2개 이상인 줄. 그 줄의 '기계수' 위치로 4묶음(싱글 · 더블 · 자카드 · 양두/테리/벨로아/기타) 칸을 찾음 (기계수 · 폭(") · 피다수 · 침수 · 가마수 · 기종)
- A칸에 이름 → 새 편직처 / 빈 칸 → 위 편직처 다음 줄 / `(풍성소개)`처럼 괄호 글자 → 메모
- 연락처: B 전화 · C 팩스(010으로 시작하면 핸드폰으로) · D 핸드폰 · E 대표/담당 — 여러 줄이면 담당자 여러 명. `010--` → `010-`
- **기종 글자 나누기**: 괄호 앞 `NNG`를 게이지로(여러 개 · `11-12G` 범위 · 60 넘는 숫자는 게이지 아님) → 제조사(금용·금융 / 쌍용 / 삼세스 / 후쿠하라·후꾸하라 / 테롯·Terrot / 오로조 / 마이어 / 창대) → 나머지는 메모
  예: `22G(금용,스판겸용)` → 22 · 금용 · 스판겸용 / `28G.22G,20G,14G-싱글4단(창대)` → 28·22·20·14 · 창대 · 싱글4단
- 숫자 없이 글자만 있는 칸 = **세부 종류 이름**('싱글(SPAN)' · '쥬리' · 'BL=OPEN기계') → 아래 줄들의 세부 종류. 이름에 제조사가 있으면 아래 줄 제조사로
- `"` = 위와 같음 · **인치가 빈 칸이면 같은 묶음 위 줄 인치**(보품섬유처럼 첫 줄에만 36을 적은 경우) — 미리보기에 'N줄 채웠어요'
- 가마수 칸에 100 넘는 숫자 = 침수가 잘못 들어간 것 → 침수로 (용상 · 한림섬유)
- `17대`처럼 기종 칸에 대수 → 대수
- 비고 칸: 편직료가 같은 줄에 있으면 '비고: 편직료' 한 줄로 편직료에 / 기계 한 줄짜리 줄이면 그 기계 메모 / 나머지는 편직처 메모
- 주소 칸: 주소처럼 생기면 주소, 아니면(소재다양 · 시직비 · 총 16대) 메모
- 미리보기: 편직처마다 새로/이미 있음 · ⚠ 확인할 것 · 펼치면 기계 표. 이름 고칠 수 있음.
  설계서 편직처 목록에 비슷한 이름(미건 ↔ 미건섬유)이 있으면 [그 이름으로 바꾸기]
- 이미 있는 이름은 처음엔 안 고름 — 고르면 덮어쓰기(연락처·주소·편직료·기계를 엑셀 값으로, 메모는 남기고 엑셀 비고를 덧붙임, 확인일 그대로)
- 가져온 편직처는 **확인일 없음** (엑셀이 언제 기준인지 모름) → '확인 필요'에 모두 보임

## 5. 확인한 것 (2026-11-23, DEV 미리보기 + 실제 엑셀)

- 실제 `편직처..xls` → 19곳 · 기계 246줄 · 적힌 대수 566대. 28G 30" 찾기 → 미건 · 미송 · 아나 · 예그린 · 태성 · 한림 · 한성 (딱 맞음 8줄 + 근접 6줄)
- 수정 창: 게이지 '7, 9' → 7G·9G 칩, 기계를 고쳐 저장하자 확인일 '오늘 확인'. 닫기 → '변경사항이 있습니다' → 저장하고 나가기
- 메모 남기기 · 설계서 [기계 현황에서 고르기] → 월드섬유 22G 32" 96F 들어감(침수는 비움) → 저장한 설계서가 월드섬유 '우리 작업 이력'에
- 휴대폰 폭: 목록 → 한 곳 보기(← 편직처 목록), 표는 옆으로 밀기
