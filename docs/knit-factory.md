## 1. 정한 것

| 질문 | 결정 (대표님) |
|---|---|
| '가마'가 뭔가 | **갈아 끼우는 실린더(게이지)**. 예: 26"에 낄 수 있는 가마가 28G · 30G · 32G |

## 2. 화면

- **[편직처]** 목록 — 편직처마다 이름 · 지역 · 기계 N대 · 가마 N개 · 확인일, 오른쪽에 **묶음(종류 + 인치)마다 요약**
  예: `싱글 30" 12대 · 지금 24·28G · 가마 18~32G` (검색 · 지역 칩 · '확인 필요 N')
  - 누르면 **상세** — **견적서 화면과 같은 모양** (대표님 요청 2026-11-23): 왼쪽 좁은 '편직처 목록'(따로 스크롤 · 고른 줄 보라색 · 검색 · 줄마다 지역 · 확인일 · 기계/가마 수 · 종류별 인치) + 오른쪽 상세
  - 상세 제목 앞 **←** = 전체 목록의 보던 자리로. 왼쪽 목록에서 다른 편직처를 누르면 오른쪽만 바뀜. 휴대폰은 왼쪽 목록 없이 상세만
- **상세** — 연락처(누르면 전화) · 주소([지도에서 보기] · [카카오맵 길찾기/찾기]) · 편직료
  - **기계 현황**: 종류 + 인치 묶음(가마를 돌려 쓰는 단위)마다 기계 줄(대수 · 피더 · **지금 가마** · 침수 · 스판장치 · 제조사 · 메모) + 아래 **보유 가마** 칩("8G 가마 6개 · 960침" — 개수는 꽂힌 것 포함, 진한 테두리 = 지금 꼽힌 게이지)
  - **지금 가마**를 누르면 바로 바꿈 (그 묶음 게이지 칩 · 직접 넣기 · 모름) → 바로 저장 + 확인일 오늘
  - 메모(날짜 · 쓴 사람) · 우리 작업 이력(설계서 · 생산 오더) · [오늘 확인함] · [수정]
- **[기계로 찾기]** — 게이지 · 인치 · 계열 · 종류 · 제조사 · 지역 · 스판장치 있는 기계만 · 검색어
  - 게이지를 넣으면 상태: **지금 꼽힘**(그 게이지가 꼽혀 있음 — 확인일 기준) → **가마 교체**(같은 종류 · 인치 보유 가마에 그 게이지) → **근접**(±1G · ±2")
  - '쓸 수 있는 가마' 칸 = 그 묶음의 게이지 전부 (지금 꼽힌 것 진하게, ×개수)
  - [찾은 N곳 지도에서 보기]
- **[지도]** (카카오맵)
  - 핀 = 편직처 (대표 주소 = 주소 첫 줄). 거르기: 지역 · 확인 필요한 곳만 · **[기계로 찾기] 조건에 맞는 곳만**
  - 핀을 누르면 카드: 요약 · 전화 · [상세 보기] · [방문에 넣기] · [카카오맵 길찾기] · [위치 다시 찍기]
  - **방문 순서**: [방문]을 누른 차례로 번호 → 다음 곳까지 직선 거리 · [길찾기](카카오맵 출발→도착) · 총 거리 · [가까운 순서로]
  - 위치를 못 찾은 곳: [찍기] → 지도를 누른 곳으로 저장 (manual)
  - 키가 없으면 키 만드는 법 + 넣는 칸 (회사 공통 저장)
- **[⚙ 기계 종류]** — 계열(그룹) · 종류 목록 (이름 · 계열 · 순서 · 추가 · 빼기)
  - 종류 이름을 바꾸면 그 종류를 쓰는 편직처 줄도 같이 바뀜 (확인 창) · 빼면 그 줄은 남고 '설정에 없음'
  - 계열은 종류가 있으면 못 지움 · '미분류'는 계열 이름으로 못 씀
- **[정리본 가져오기]** — 정리본(.json) 미리보기(편직처마다 '확인할 것' 노란 칸) → 옵션: 지금 편직처 모두 지우기 · 설계서 편직처 목록에서 안 쓰는 이름 빼기(뺄 이름 미리 보여 줌) · 설정에 없는 종류 더하기
- **상세 [기계 수정]** (대표님 요청 2026-11-24 '이 화면에서 바로, 그게 간단') — 기계 현황 카드가 그 자리에서 입력 칸으로 바뀜 (`KnitEquipmentEditor`)
  - 카드 = 종류 + 인치. 카드 머리에서 종류 · 인치를 바꾸면 그 카드의 기계 · 가마가 같이 바뀜 · [🗑] 카드 지우기
  - 기계 줄: 대수 · 피더 · 지금 가마 · 침수 · 스판장치 · 제조사 · 메모 — [+ 기계 줄] · 복사 · 지우기 (**피더는 기계마다**, 가마에는 없음)
  - 보유 가마: 게이지 · 가마 개수(꽂힌 것 포함) · 침수 · 메모 — [+ 보유 가마] · 지우기 · '18, 22, 24' 한 번에 넣기 (있는 게이지는 안 겹침)
  - [+ 종류 · 인치 추가] 새 카드 · 아래 붙어 있는 [저장](한 번에 · 확인일 오늘) / [취소](버릴까요?)
  - 저장 안 한 변경이 있으면 왼쪽 목록 · ← · 보기 단추 · 위 메뉴로 나갈 때 '버리고 나갈까요?'
- **[+ 편직처 추가] / [정보 수정]** — 기본 정보 · 담당자 · 주소(첫 줄 = 대표 → 지도) · 편직료만 (기계 · 가마는 상세 [기계 수정]에서)
  - 대표 주소가 바뀌면 좌표를 다시 찾음(키가 있을 때)
- **설계서 편직 사양은 기계 현황에서만** (대표님 요청 2026-11-24) — 편직처 · 기종 · 게이지 · 인치 · 침수 · 피더 칸은 직접 칠 수 없고, 누르면 [기계 현황에서 고르기] (조직 · 개폭 · 특이사항은 그대로 직접)
  - 기종 = 기계 현황 종류 이름(싱글 · 양면 자카드 …) · 침수가 기계 현황에 없으면 계산 값을 넣고 칸에 '≈ 계산 값' (`knitLink.needleEstimated`) · 피더 = 고른 기계 줄의 피더 · 고르기 창의 [편직 사양 비우기]
  - 고른 기계는 설계서 `knitLink`(편직처 id · 종류 · 인치 · 게이지 · 기계 줄 id)에 남김 — 편직 칸이 아니라서 변경 이력에는 안 남음
  - **알람**: 설계서 편직처 · 종류 · 인치 · 게이지가 기계 현황에 없으면 편직 사양 위 빨간 줄 (`sheetKnitAlarm`) + [기계 현황에 이 가마 추가](그 편직처 · 종류 · 인치에 가마, 묶음이 없으면 기계 줄도 — 확인일은 안 바꿈) · [기계 현황에서 다시 고르기]
    기종이 예전 글자('SINGLE')이거나 여러 기계가 맞으면 노란 줄('다시 골라 주세요'). 개발/설계 현황 · 설계서 보관함 줄에도 '⚠ 기계 현황에 없음'
  - **[설계서 맞추기]** (편직처 화면 위, 빨간 숫자 = 알람 설계서 수) — 예전 설계서를 기계 현황에 맞추는 창 (`KnitSheetAlignModal`, `proposeSheetAlignment`)
    · 편직처 이름 · 기종을 기계 현황에 맞춤 · 침수 · 피더는 설계서 값이 있으면 그대로(다르면 '다른 값'), 비었으면 기계 현황 값(침수 없으면 ≈)
    · 같은 게이지 기계가 여럿이면 설계서 피더와 같은 기계 · 애매하면 같은 계열(미건 '더블' → 양면 자카드) · 기종 빈 칸은 같은 편직처 · 같은 조직 설계서를 따름
    · 기계 현황에 없는 설계서는 안 바꾸고 알람만 · 저장하면 설계서 변경 이력 '편직처 기계 현황에 맞춤' (`App.alignSheetsToKnit`)
- **설계서 편직 사양 [기계 현황에서 고르기]** — 설계서 게이지 · 인치로 걸러 [기계로 찾기] → 기계 + 게이지(지금 가마 또는 보유 가마) → '바뀌는 칸' → [설계서에 넣기]
  - 넣는 칸: 편직처 · 게이지 · 인치 · 침수(기계 · 가마에 적힌 값만) · 피더(숫자만). 가마를 바꿔야 하면 "지금 ○G가 꼽혀 있어서 ○G 가마로 바꿔야 해요"
  - body에 바로 띄움(포털) — 설계서 창의 배경 흐림 안에서는 fixed 창이 잘렸음
